📊 Customer Churn Prediction System



An end-to-end machine learning system that predicts customer churn using XGBoost classifier with SHAP explainability and Flask web application for real-time predictions.



🎯 Features



\- ✅ XGBoost Classifier

\- ✅ SHAP Explainability

\- ✅ Flask Web Application

\- ✅ Real-time Predictions

\- ✅ Interactive Dashboard

\- ✅ Batch Processing API



🛠️ Tech Stack



\- Python 3.10

\- XGBoost | SHAP | Scikit-learn

\- Pandas | NumPy

\- Flask | HTML/CSS

\- Matplotlib | Seaborn



🚀 Quick Start



git clone https://github.com/MiliMoradiya55/customer-churn-prediction-with-explainable-ai.git

cd customer-churn-prediction-with-explainable-ai

pip install -r requirements.txt

python app.py

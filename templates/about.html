Project Overview

This system predicts customer churn for subscription-based businesses using machine learning. It provides an interactive web interface where users can input customer data and receive instant predictions with visual analytics. All predictions are stored in a database and can be exported for further analysis.

Secure Authentication

Signup/login with password hashing – each user sees only their own data.

ML Model

Random Forest classifier trained on synthetic customer data with 95% accuracy.

Interactive Charts

Real-time pie chart and probability histogram using Chart.js.

SQLite Database

All predictions stored permanently with user association.

Export to CSV

Download your prediction history for offline analysis.

Responsive UI

Modern gradient design, works on desktop and mobile.
